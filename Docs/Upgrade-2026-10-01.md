# Dragon MMA Idle — 비주얼·시스템 업그레이드

## 편집 구조 전환 추가

화면을 실행 시 생성하는 방식에서 저장된 Canvas·시설/캐릭터 프리팹·Animation Clip/Animator Controller 방식으로 전환했습니다. 가격·전투력·시간·응원·수레 용량 등은 `Configuration/DefaultGameConfig.asset`에서 편집합니다. 사용 방법은 [Unity 편집 안내](Editor-Authoring-Guide.md)를 참고하세요.

전환 검증은 EditMode 58개 통과, 실제 씬의 위치·색·고정 문구 수정 유지, 수련 애니메이션의 갱신 중 연속 재생, 판매/수련/페이지 버튼으로 확인했습니다. 아래 기존 업그레이드 검증 수치는 전환 전 기록입니다. 현재 검증 화면은 `Artifacts/authored-*-final.png`, 정지 상태 씬 미리보기는 `Artifacts/authored-editor-storage.png`입니다.

## 실행

`Builds/Windows-Upgrade/DragonMMAIdle.exe`를 실행합니다. 기존 `Builds/Windows`는 남겨 두었습니다.

- 자동 사냥: 이동10초 → 전투20초. 전투 화면 클릭·터치 또는 포커스 상태의 Space로 응원.
- 응원: 1회+0.2%p, 최대+10%p. UI 버튼은 응원에서 제외.
- 수레 귀환: 전투를 멈추지 않고 현재 화물을 즉시 수용소로 이전.
- 수용소: 개체 선택·페이지 이동 → 판매 또는 수련 배치.
- 판매: 두 슬롯의 타이머가 끝나면 각 수령 버튼을 누름.
- 수련방: 80G 개방. 완료된 용은 남아서 연습하며, 회수·교체 가능.
- 거점 보기: 창이 위로 확장. 접기·Esc로 닫음. 설정에서 항상 위 표시 전환·저장 가능.

## 비주얼

오리지널 픽셀 에셋105개로 교체했습니다. 인간과 용의 프레임은40×30px이며, 화면에서는 확대 표시합니다. 5종 용의 실루엣을 구분하고 숲 바닥·나무·수풀·수레·수련방·샌드백을 추가했습니다. 펀치·킥·클린치·테이크다운·피격·승리 동작, 파워 펀치 강화 이펙트, 포획 적재와 보조 인물의 수레 퇴장 연출을 연결했습니다.

## 시스템

첫 조우 새끼용 보장, 이전 종 최초 포획 후 다음 종 해금, 해금 시점부터 등장 보정을 계산합니다. 전투 시작 시 판정값을 준비하고 마지막 판정 직전까지 응원을 반영합니다. 최초 수련의 전투력·기술은 종별1회, 용핵은 개체별1회입니다. 완료 용은 수련방에 남으며 반복 보상을 주지 않습니다. 오프라인은 진행 중이던 수련·판매만 완료하고 사냥하지 않습니다.

게임 규칙·화면·Unity 입력·Windows 창 제어를 분리했습니다. 저장은 v2 개체 ID 구조로 변환하며 기존 v1 진행을 이관합니다. 원자적 저장과 이전 저장 백업, 손상 파일 보관·복구를 추가했습니다. 사용자 저장과 테스트 저장을 분리해 검증했습니다.

관상용 방, 전체 수령, 자동 수확은 기획서의 후속 범위로 안내만 표시합니다.
