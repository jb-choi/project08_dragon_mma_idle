# 첫 숲 새끼용 전투 — 초반 20초 스토리라인

## 계약과 레퍼런스

첫 전투는 초보 파이터가 작은 용의 반응을 읽고 기본 잽으로 대응하는 장면이다. 기술의 화려함보다 서로 보고, 먼저 건드리고, 용의 반응을 기다리는 인과를 보여준다. 사용자에게 긍정 평가를 받은 Jab–LightHit 그림/접촉/회수는 그대로 유지한다.

- [Nintendo 개발자 인터뷰: 타이밍의 힌트](https://www.nintendo.com/en-gb/Iwata-Asks/Iwata-Asks-PUNCH-OUT-/PUNCH-OUT-/4-Initially-a-Golf-Prize-/4-Initially-a-Golf-Prize-230647.html): 공격이 통하는 시점을 읽게 하는 단서가 있다는 설계 설명을 참고했다. 이번 적용은 숨은 신호가 아니라, 첫 용의 입/앞발 위협을 충분히 보여주고 끝난 뒤 반격하도록 한 해석이다.
- [Super Punch-Out!! 공식 매뉴얼](https://www.nintendo.com/es-es/games/oms/snes-classic/manuals/punch-out/manual.pdf): p2의 기본 펀치/가드/회피 분리와 p7의 조건부 강공을 참고했다. 첫 전투에는 기본 잽과 가드만 사용한다. 상대 기술/게임 규칙/그림을 복제하지 않는다.
- 원본 프로젝트 기획서 `../# Dragon MMA Idle v0.1.txt`: 시작 파워10, 전투20초, 응원은 승률 보조, 기술은 성장 보상으로 해금. 새 전투 조율은 연출이며 밸런스 변경이 아니다.

## 액션 진행

| 구간 | 액션과 의도 |
|---|---|
| 0–1.5초 | 서로 관찰, Fighter 가벼운 가드/체중 이동, 용 느린 호흡. 강적처럼 즉시 돌진하지 않는다. |
| 1.5–5.5초 | 조심스러운 단발 잽 2회. 접촉1.70/3.80초, 짧은 머리 recoil, 충분한 회수/쉼. |
| 5.5–7.6초 | 첫 위협: 용이 입과 앞발로 허세, 파이터는 펀치를 멈추고 가드를 올린다. 실제 공격 접촉/피해로 위장하지 않는다. |
| 7.6–11.6초 | 앞발이 내려간 빈틈에 잽, 한 번 더 확인. 접촉7.80/9.20초. |
| 11.6–13.5초 | 같은 위협 신호를 다시 보여준다. 가드 유지 후 용의 회복을 기다린다. |
| 13.5–16초 | 짧은 잽–잽, 접촉13.70/14.50초. 큰 기술 대신 조금 붙은 자신감을 박자로 표현한다. |
| 16–20초 | 호흡, 마지막 단발 잽18.00초, 회수/가드로 결착을 기다린다. |

20초 이후 승패·포획·패배/회복 판정은 기존 세션이 담당한다. 포획 성공 때는 같은 초록 새끼용이 고개와 앞다리를 낮추는 항복 동작으로 연결하며, 파이터는 자세를 지킨다. 승리를 미리 연출하거나 강제하지 않는다. Baby 종 전투에 동일한 입문용 흐름을 적용하며 최초 한 번만의 세이브 플래그는 추가하지 않는다. 다른 용, 훈련, 일반 Idle, 승인된 BASIC JAB QA 모드는 유지한다.

## 구현과 검수 기준

`BabyFirstBattle`는 기존 Frame/접촉 시계를 재사용한다. main view와 Animation Lab COMBAT/Baby가 같은20초 타임라인을 사용한다. BASIC JAB는 기존2.233초 독립 반복 검수로 남긴다. 전투 길이 설정이20초와 다르면 상대 비율에 맞춰 타임라인을 매핑한다.

필수 검수: 7회의 잽 접촉 유지, 위협 중 동시 펀치/가짜 피해/소리 없음, 가드 전환과 발 위치/체형 연속성, 더블 잽 후 회수, 종료 전 조기 승리 없음, 작은640×240 실제 렌더, 승/패 정상 연결, 다른 용과 기존 QA 회귀 없음. 테스트 숫자로 액션의 가독성을 대신하지 않는다.

실제 화면에서 기존 block 전환은 발 위치가 튀었고, 기존 defeat 결과는 초록 새끼용을 주황색 구형 용으로 교체하며 크기와 파이터 위치도 바꾸었다. 별도 `fighter_first_guard`와 `dragon_0_yield`를 추가해 해결했다. 두 클립의 첫 프레임은 승인된 FightIdle의 실제 픽셀을 재사용하며 고정 바닥·캔버스·스케일로 등록한다. 승인된 Jab/LightHit와 기존 block/defeat 자산은 덮어쓰지 않았다. 새로운 프리로드 계약은 340 sprites / 25 textures다.

결과/회복에서도 BasicCombatProfile의 같은 위치·체형 기준을 유지한다. 포획 카트 아이콘의 Baby 초상만 같은 초록 그림으로 바꾸고 다른 종은 유지했다. 첫 전투 결과 알림은 왼쪽으로 옮겨 얼굴/항복 동작을 가리지 않으며, 다른 단계/종에서는 원래 위치로 복원한다. 포획 카트 전달과 승률/보상/응원/저장 규칙은 유지한다. 패배 때 기존 파이터 넘어짐/회복을 유지하고 상대는 초록 몸을 유지한 채 UI fade로 퇴장한다.

## 이전 QA가 체감 품질을 못 올린 원인

이번 화면 관찰에 기반한 판단이다. 클립 수·정상 재생·자동 테스트 통과가 주로 개선 목표여서, 초반 캐릭터의 행동 동기와 한 교환에서 다음 교환/결과로 이어지는 시각적 연속성이 합격 기준에 충분히 들어가지 않았다. 좋은 잽 하나가 있어도 가드에서 발이 튀거나 결과에서 색·크기·위치가 바뀌면 전체 장면의 품질은 떨어진다. 이번에는 기술을 더 늘리기보다 20초의 관찰→반응→대기→반격 문맥과 실제 작은 화면의 결과 연결을 검수 대상으로 삼았다. 전체 게임의 재미가 해결되었다는 결론은 아니다.
